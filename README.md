# Project-Bella Pizza
## Bella Pizza — Site de Pizzaria

Desenvolvimento de um site responsivo para uma pizzaria, com funcionalidades voltadas à apresentação do cardápio e à interação dos clientes com o estabelecimento.

O projeto contempla uma interface para visualização dos produtos, cadastro e login de usuários, além de recursos para contato e realização de pedidos. Também foi desenvolvida uma funcionalidade para consulta do histórico de pedidos, permitindo ao usuário acompanhar suas solicitações anteriores.

**Principais funcionalidades:**
- Apresentação do cardápio e dos produtos da pizzaria.
- Cadastro e login de usuários.
- Interface para realização de pedidos.
- Consulta ao histórico de pedidos.
- Área de contato com o estabelecimento.
- Layout responsivo para diferentes dispositivos.

**Tecnologias utilizadas:** HTML5, CSS3 e JavaScript.
